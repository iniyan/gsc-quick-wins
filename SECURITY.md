# Security Policy

## Scope

gsc-quick-wins is one `SKILL.md` plus one standard-library Python script
(`skills/gsc-quick-wins/scripts/find_quick_wins.py`) that only reads the CSV you
give it. It makes no network calls, runs no shell commands, reads no
environment variables and writes no files.

## Supported versions

Only the latest release is supported. Please upgrade before reporting.

## Reporting a vulnerability

Please report vulnerabilities privately by email to **thamiz@iniyan.in**. Do
not open a public issue. You will get a reply within 7 days.
