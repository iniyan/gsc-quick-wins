No new articles. More traffic.

An Agent Skill that finds the keywords Google already ranks you for in positions 4–20, and writes the exact fixes to move them to page one.

Install the skillView on GitHub

Your easiest wins are already on page one and a half.

Positions 1–3 are winning already. Past 20, you're too far away to move quickly. In between sit pages Google half-trusts: good enough to show, not good enough to pick. A #8 to #3 move can bring more clicks than ten fresh posts.

This skill reads your Search Console export, works out why each page is stuck — content gap, weak title, or too few internal links — and hands you the fix, written out.

How it works

  1. ExportSearch Console → Performance → last 3 months → Download CSV.
  2. FilterKeep positions 4–20, sort by impressions, compare CTR to the benchmark for each position.
  3. DiagnoseContent gap, CTR problem or authority problem — per page, not in general.
  4. FixRewritten title and meta, the H2 to add, FAQs, schema and internal links. Then re-submit.

From the sample export in the repo. The agent then writes the fixes for each row.

Install

Works with Claude Code, Claude.ai, Codex CLI, opencode, Antigravity, Cursor and any agent that reads SKILL.md.

Claude Code

/plugin marketplace add iniyan/gsc-quick-wins
/plugin install gsc-quick-wins@gsc-quick-wins

Any other agent

npx skills add https://github.com/iniyan/gsc-quick-wins --skill gsc-quick-wins

Claude.ai

Download the zip from the latest release, then upload it under Settings → Capabilities → Skills.

Then ask

/gsc-quick-wins — here's my Queries.csv. Find my quick wins.
